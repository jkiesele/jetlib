Summary

The branch makes the jet selection and the seed configurable. It removes neutrinos and, by default, prompt leptons before clustering, and changes the default η range to −3 < η < 3. It also fixes the remaining review findings: crashes, silent failures, memory growth, missing provenance, the Python bindings, and the build.

Several changes alter what a DICE jet library contains. Each one was requested. The rest were checked to leave the tree identical for a fixed seed.

What users of existing jet libraries need to know.

A new default production is not comparable to an old one. It covers −3 < η < 3 instead of η > 1.7, contains no neutrinos, and contains no prompt leptons. Pass --eta-min 1.7 --eta-max 100 --keep-prompt-leptons to get closer to the old selection. Neutrinos cannot be put back.

Code that reads jetConsituentsEta needs the new name. In Python, PseudoJet.phi() now returns [−π, π), and phi_02pi() gives the old range.

Not done, by decision: the per-jet scalars stay length-1 vectors (finding 5.2), to keep the format DICE reads.

Runtime and memory

Master and the branch build run the same events: the same seed per repetition, tt̄, with each run single-threaded. checks/timing.py measures the jetlib process itself inside the container. branch, master selection runs the branch with --eta-min 1.7 --eta-max 100, which approximates master's selection, so the effect of writing more jets can be told apart from everything else. Values are medians over the repetitions.

VariantEventsWall [s]CPU [s]CPU range [s]CPU / event [ms]Max RSS [MB]Jets written

Wall time depends on the load of the shared machine. In a first round with 12 runs in parallel, the branch was up to 6% slower in wall time, but not in CPU time. The gap disappeared with 6 runs in parallel and in a separate test writing to local disk versus /ceph, so it was load, not the code.

How it was verified

  • checks/check_output.py: __CLICHECKS__ checks passed:
    • defaults equal master at commit B, before the particle-content change;
    • seed behaviour;
    • the selection options;
    • no neutrinos, and the prompt-lepton switch;
    • index branches and provenance;
    • 13 invalid arguments, a config typo, an unwritable output, and --help;
    • the default config outside build/;
    • the default output identical to the reference build taken after Phase 2, for the same seed.
  • checks/check_bindings.py: __PYCHECKS__ checks passed (container run plus --verify on the host):
    • invalid filters are rejected;
    • filters write exactly the jets selected by direct evaluation;
    • jet lifetime, the error translation, JetAnalysis reuse, and φ.
  • Refactors that should not change the output (robustness, streaming, bindings) were compared branch by branch against the earlier build for a fixed seed: identical.
  • Builds tested: a fresh configure, -DJETLIB_PYTHON=OFF, and a wrong FASTJET_DIR, which gives a clear error.

Details for every finding and fix are in REVIEW.md on the branch.
